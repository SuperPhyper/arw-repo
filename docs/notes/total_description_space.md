# The Total Description Space D(S) — superseded

Superseded by `docs/notes/scope_fibration.md` on the day of creation, following
external review. Reasons for the rename and supersession:

1. **Name over-promised.** "Total description space" suggests the space of all
   descriptions of a system; the object actually defined is the family of
   scope-induced cover constructions indexed by scope parameters — for which
   *scope fibration* is the accurate name (the rename candidate was already
   flagged in this file's own delimitation section).
2. **Content extended, not just renamed.** The successor adds: the
   bundle-vs-fibration distinction (falsification categories as obstructions to
   local triviality), §2b (four directions as four morphism types; path-vs-functor
   distinction for transfer), and the §5a resolution of the paper part of
   Q-DSP-01 (2σ̄-interleaving; exact commutativity on ε-plateaus).

All content of this file is contained in the successor. The Q-DSP-01–04 series,
originally registered from this file, is now owned by
`docs/notes/scope_fibration.md`.
